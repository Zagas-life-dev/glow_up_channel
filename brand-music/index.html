UP music beds

Five background tracks made entirely in code, so they're ours to use anywhere. They're built to be interchangeable: swap one for another in any film and nothing else has to change.

Any lengthRender to a film's exact duration. Whole bars fill the time.
Ending on cueThe final chord lands where you say, e.g. on the UP end card.
Same loudnessEvery track is mixed to the same level (~-18.5 dB mean), so the volume never needs resetting.
Same shape2-bar intro, then 8-bar A/B sections. B is fuller, so cuts on section lines feel natural.

Using one in a film

Render the bed at the film's length, with the ending on the end-card time. Run it from the film's project folder, using the path to brand-music/ from there:

node ../brand-music/make-music.mjs afroglow 101 assets/audio/music.wav --end-at 95.4

Then place it like any music bed, the same tag every UP film already uses:

<audio id="mx" src="assets/audio/music.wav" data-start="0" data-duration="101" data-track-index="20" data-volume="0.4"></audio>

To swap tracks, change only the track name and re-run the command. Length, ending and loudness all stay the same. Under a voice-over, keep data-volume around 0.25–0.3; for music-only cuts, 0.4–0.5.

The previews above are 60s renders with the ending at 57s. To rebuild them, run node brand-music/make-music.mjs with no arguments.
